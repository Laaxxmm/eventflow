# Race Ink placeholder photography

Per-sport stock photos used on event pages until the organiser uploads a hero photo, and on
the marketing site. `App\View\SportImagery` reads `<set>/*.jpg|jpeg|webp` in file-name order:

| Set | Used for | Suggested shots |
| --- | --- | --- |
| `marketing/` | `/` hero (01), auth panel (02) | wide race start, runners over the camera |
| `running/` | running events: 01 hero, 02 Night Circuit, 03 Equipment Close (shoes), 04 schedule | start line, pack, shoes close-up, crowd |
| `cycling/` | cycling events, same slots | peloton, bike close-up, criterium corner |
| `skating/` | skating events, same slots | rink race, inline skates close-up |
| `generic/` | any other sport, and the fallback for empty sets | stadium, finish line |

Rules: action or equipment, no posed stock smiles, no visible third-party logos as the subject.
Landscape 2400 px wide, JPEG quality ~80, under 400 KB each. Name files `01.jpg`, `02.jpg`, ...

Only use photos you are licensed to publish (e.g. the Unsplash License, or your own). List each
file below with its source and photographer.
